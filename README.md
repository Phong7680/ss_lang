# Scheme風インタプリタ

このプロジェクトは、Lisp/Scheme風の言語を解釈・実行するインタプリタです。

## 概要

このインタプリタは、以下のコンポーネントで構成されています：

- **トークナイザ (tokenizer.c/h)**: 字句解析を行い、入力テキストをトークン列に変換
- **パーサ (parser.c/h)**: トークン列を構文木に変換
- **評価器 (evaluator.c/h, evaluator_hatten.c)**: 構文木を評価して結果を計算
- **環境 (environment.c/h)**: 変数と関数の名前空間を管理
- **木構造 (tree.c/h)**: 構文木のデータ構造を実装
- **ベース (base.c/h)**: 基本的なデータ構造とユーティリティ関数

## 言語仕様

### 字句構文

```
字句     -> ( | ) | 数 | 名前

数       -> 符号? 数字 数字*
名前     -> 符号 | 開始文字 後続文字*
開始文字 -> 英字 | 記号
後続文字 -> 英字 | 記号 | 数字 | 符号

符号     -> + | -
数字     -> 0 | 1 | … | 9
英字     -> a | b | … | z | A | B | … | Z
記号     -> * | / | % | ^ | = | < | > | ! | ? | $ | & | : | _ | ~ | .
```

### 処理系向け文法

```
プログラム -> 文*

文 -> ( def 名前 式 )                   定義文
    | ( fun ( 名前 名前* ) 式 )         関数定義
    | 式                                式文

データ -> 数 | 名前 | ( データ* )        データリテラル

式 -> 数                                数値リテラル
    | 名前                              変数参照
    | ( if 式 式 式 )                   条件式
    | ( 名前 式* )                      関数呼び出し
    | ( data データ )                   データ式
    | ( do 文* 式 )                     局所式
```

### 組み込み関数

以下の組み込み関数が利用できます：

- `head`: リストの先頭要素を取得
- `rest`: リストの先頭以外の要素を取得
- `cons`: リストの先頭に要素を追加
- `null?`: リストが空かどうかを判定
- `number?`: 数値かどうかを判定
- `name?`: 名前（シンボル）かどうかを判定
- `list?`: リストかどうかを判定

### 記法

- `Ｘ*`: Ｘの0個以上の並び（Ｘの列）
- `Ｘ?`: 0個か1個のＸ（省略可能なＸ）

## プログラム例

このインタプリタで実行できるプログラムの例を以下に示します。

### 最小値を求める関数

```scheme
(fun (min x y) (if (< x y) x y))
```

2つの値を比較し、小さい方を返します。

### 階乗を計算する関数

```scheme
(fun (fact n) (if (= n 0) 1 (* n (fact (- n 1)))))
```

再帰を使って階乗を計算します。例：`(fact 5)` → 120

### 最大公約数を求める関数（ユークリッドの互除法）

```scheme
(fun (gcd m n) (if (= n 0) m (gcd n (% m n))))
```

2つの整数の最大公約数を計算します。

### リストの長さを求める関数

```scheme
(fun (length l) (if (null? l) 0 (+ 1 (length (rest l)))))
```

リストの要素数を再帰的に数えます。

### リストを連結する関数

```scheme
(fun (append l1 l2) (if (null? l1) l2 (cons (head l1) (append (rest l1) l2))))
```

2つのリストを連結して新しいリストを作成します。

### 挿入ソート

```scheme
(fun (ins-sort l) 
  (do 
    (fun (ins a l) 
      (if (null? l) 
        (cons a l) 
        (do 
          (def b (head l)) 
          (if (< a b) 
            (cons a l) 
            (cons b (ins a (rest l)))))))
    (if (null? l) 
      l 
      (ins (head l) (ins-sort (rest l))))))
```

挿入ソートアルゴリズムを実装した例です。リストを昇順にソートします。

## ビルド方法

### 前提条件

- GCC（GNU C Compiler）
- Make

### `ss` インタプリタのビルド

```bash
make ss
```

このコマンドにより、以下のオブジェクトファイルがコンパイルされ、`ss` 実行ファイルが生成されます：

- `base.o`
- `tokenizer.o`
- `parser.o`
- `tree.o`
- `evaluator_hatten.o`
- `environment.o`
- `ss.o`

## 実行方法

### プログラムファイルの実行

```bash
./ss <プログラムファイル.ss>
```

**例：**

```bash
./ss program1.ss
./ss program2.ss
./ss comment.ss
```

### サンプルプログラム

プロジェクトには以下のサンプルプログラムが含まれています：

- `program1.ss`: サンプルプログラム1
- `program2.ss`: サンプルプログラム2
- `comment.ss`: コメントのテスト用プログラム

## Makefile のターゲット

- `make ss`: インタプリタをビルド
- `make clean`: オブジェクトファイルと実行ファイルを削除
- `make cleanall`: 生成した全ファイルを削除
- `make all`: 全てのテストプログラムを実行し、出力ファイルを生成

```
├── program2.ss       # サンプルプログラム2

```
